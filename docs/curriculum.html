00 · BOOT

Three commands and you're running

The whole curriculum runs on either Anthropic or OpenAI. Pick one, drop the key in .env, and every lesson works without further config.

▷ quick start

uv sync                                       # installs everything
cp .env.example .env                          # then fill in ANTHROPIC_API_KEY
uv run python -m lessons.00_setup.example     # smoke test

Don't have uv? Grab it from docs.astral.sh/uv. The capstones that need extras: uv sync --extra api and uv sync --extra dev.

PATTERN

The switchable LLM provider layer

Lessons never instantiate ChatAnthropic or ChatOpenAI directly. They call get_llm() and the right model comes back. Flipping providers is one env var.

.env  (LLM_PROVIDER=openai)
        │
        ▼
shared/settings.py  ──►  settings.llm_provider
        │
        ▼
shared/llm/base.py  ──►  get_llm()  ──►  openai_adapter.build()
                                       └►  anthropic_adapter.build()

Adding a new provider (Gemini, Ollama, anything) is one file:

1. uv add langchain-google-genai
2. Create shared/llm/google_adapter.py with a build() function
3. Add google_api_key to shared/settings.py
4. Register it in shared/llm/base.py:

   _ADAPTERS = {
       "anthropic": anthropic_adapter.build,
       "openai":    openai_adapter.build,
       "google":    google_adapter.build,  ← new
   }

That's the whole change. No lesson code needs to be touched.

DEBUG

The ipdb recipe

Lesson 03 covers this in depth. Here's the cheat sheet you'll come back to.

▷ Drop into ipdb at any breakpoint()

PYTHONBREAKPOINT=ipdb.set_trace uv run python -m lessons.NN_topic.example

▷ The commands you'll use 90% of the time

  • n — next line
  • s — step into a call
  • c — continue to next breakpoint
  • p x — print x
  • pp x — pretty-print x
  • w — stack trace (where am I?)
  • l — list source around current line
  • u / d — move up/down stack
  • !expr — execute Python (mutate state)
  • q — quit

▷ Async works too

ipdb> await chain.ainvoke({"language": "French"})

In production you graduate to LangSmith — set LANGSMITH_TRACING=true in .env and every Runnable + node becomes a clickable trace.

GLOSSARY

The vocabulary you'll meet

TermOne-line meaning
Runnable LangChain's base unit — anything with .invoke / .stream / .batch / .ainvoke
LCEL LangChain Expression Language — composing Runnables with the | pipe
StateGraph LangGraph's stateful workflow primitive
MessagesState A built-in state type with a messages list and an append reducer
Node A function (state) → partial_state that runs at a graph step
Edge A directed transition between nodes — static or conditional
ToolNode A prebuilt node that executes any tool_calls from the last AI message
Reducer A function that decides how new state values merge with existing ones
Checkpointer Persistence layer — saves graph state after every step
Thread A conversation id (thread_id) used to scope checkpoints
Interrupt A pause point that yields to a human, then resumes with Command(resume=...)
Middleware Composable hooks around create_agent: before_model, wrap_tool_call, etc.
Supervisor A boss agent that routes work to specialised worker agents
Swarm A flat group of agents that hand off to each other directly
Store Long-term memory API — survives across threads, keyed by namespace
Handoff tool A specially-shaped @tool that transfers control between agents in a swarm
